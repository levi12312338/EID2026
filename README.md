# Willkommen zur Einführung in die Programmierung mit Python!

In diesem Projekt finden Sie eine vorbereitete Struktur, um im aktiv im Kurs mitzuarbeiten. 

## Kapitel aktiv bearbeiten!

Arbeiten Sie die Lehrvideos und das Skript ***aktiv*** durch und ***programmieren Sie direkt mit***!

Sie finden im Verzeichnis `src` für jedes Kurskapitel ein Unterverzeichnis. 
In jedem Kapitel-Verzeichnis finden Sie ein Jupyter-Notebook zur Bearbeitung des Kapitels, z.B. `src/kapitel_01/kapitel_01.ipynb`. Nutzen Sie die Möglichkeiten des [*Literate Programming*](https://de.wikipedia.org/wiki/Literate_Programming), um sich Notizen zu machen und Fragen zu notieren (*Markdown-Zellen*) und aktiv mitzuprogrammieren (*Python-Zellen*)!

Wenn Sie den Code kopieren und einfügen, dann können Sie direkt mit ihm ***experimentieren***. Sie nehmen sich jedoch eine wichtige Chance zum Lernen.

Wenn Sie den Code nicht kopieren, sondern ***selbst tippen***, lernen Sie noch viel **aktiver** und geben sich selbst eine eine ***Gelegenheit***, das Getippte ***zu verarbeiten*** und dann besser zu verstehen. Wahrscheinlich werden Sie sich dann und wann einmal vertippen, aber auch das ist eine ***Chance***, über die Syntax der Programmiersprache nachzudenken!

## Aufgaben lösen!

Programmieren ist auch Handwerk. ***Sie lernen es, indem Sie es tun.*** Zuschauen genügt nicht! ***Lösen Sie alle Übungsaufgaben selbst. Nehmen Sie sich dafür Zeit!***

Sie finden die Übungsaufgaben mit einer Anleitung, z.B. `aufgaben_01.md`, im jeweiligen Kapitel-Verzeichnis im Unterverzeichnis `aufgaben`, z.B. `src/kapitel_01/aufgaben/aufgaben_01.md`.

Alle Aufgaben können Sie mit dem Erlernten aus dem Kapitel und den Kapiteln zuvor lösen! Manchmal finden Sie in der Aufgabenstellung zusätzliche Unterstützung.

***Auf geht's! Ich wünsche Ihnen viel Erfolg und Freude!*** 🥳 🚀
